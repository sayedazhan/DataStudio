# Scenario Studio v1.1 — Readability Upgrade

This release keeps Scenario Studio v1 functionality unchanged and improves readability across the Scenario workspace.

Changes include:
- Larger mode-tab labels and descriptions on desktop.
- Larger step headings, helper text, field labels and selectors.
- Larger assumption-card labels and inputs.
- Larger result cards, outcome labels and comparison annotations.
- Larger sensitivity, segment-table and methodology text.
- Mobile font sizing remains responsive and compact.

No backend calculation logic or API behavior changed.
