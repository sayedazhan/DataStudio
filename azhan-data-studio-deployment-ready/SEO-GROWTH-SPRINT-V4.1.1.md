# Azhan Data Studio v4.1.1 — SEO Growth Sprint 1

## Goal
Expand organic search visibility without changing the core analysis workflow.

## Changes
- Repositioned the Data Quality Checker around the Search Console query theme `excel data quality checks`.
- Repositioned the Dashboard Generator around long-tail searches such as `create dashboard from Excel automatically`.
- Strengthened the CSV/Excel analysis landing page around `analyse Excel data online` intent.
- Added illustrative example sections to the Data Quality and Dashboard pages.
- Added related-resource internal links between tools and guides.
- Added four original guide pages:
  - `/guides/check-excel-data-quality`
  - `/guides/create-dashboard-from-excel`
  - `/guides/analyse-excel-data-online`
  - `/guides/compare-excel-files`
- Added Article, HowTo and Breadcrumb structured data to the new guides.
- Expanded `/features` into a combined Tools & Guides hub.
- Updated sitemap routes and last-modified date.
- Updated frontend/software version to 4.1.1.

## After deployment
1. Confirm all four guide URLs return 200 and render correctly.
2. Open `https://azhandatastudio.com/sitemap.xml` and confirm the new guide URLs are present.
3. In Google Search Console, inspect and request indexing for the four guide URLs.
4. Re-request indexing for the updated Data Quality Checker and Dashboard Generator pages.
5. Monitor Search Console impressions over the next 2–4 weeks, especially long-tail queries rather than clicks alone.
