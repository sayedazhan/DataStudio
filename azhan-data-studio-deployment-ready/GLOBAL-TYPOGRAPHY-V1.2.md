# Azhan Data Studio — Global Typography v1.2

This release applies the larger readability treatment introduced in Scenario Studio v1.1 across the full application.

## Updated areas
- Analyse Single File landing and results workspace
- Overview, Insights, Explore, Data Quality and Fields
- Workbook / sheet selection
- Compare Datasets
- Explain Change v2
- Forecast Studio
- Scenario Studio (kept at the established v1.1 scale)
- Support controls, navigation tabs, buttons, helper text and tables

## Design intent
- Preserve the existing layout, spacing and Deep Blue visual identity.
- Increase small labels and supporting text by roughly 1–2 px where needed.
- Make tables, cards and analytical evidence easier to scan on desktop.
- Keep mobile sizing responsive.
- Do not change print/PDF report sizing.

No analytical calculations, API endpoints or backend logic were changed in this typography release.
