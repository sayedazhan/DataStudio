# Statistics Dashboard v1.1

This release changes Statistics Studio from a technical test form into a plain-language dashboard experience.

## Main changes
- Everyday-language questions replace statistical test names in the main UI.
- Results render as KPI cards + visual evidence + a plain-English conclusion.
- Technical terms such as p-value, Pearson r, Spearman rho, Welch t-test, ANOVA, chi-square and Cramer's V are moved into an expandable **Technical statistical details** section.
- The underlying deterministic statistical calculations are unchanged.
- Existing Analyse, Compare, Forecast and Scenario functionality is unchanged.

## Plain-language question modes
1. Understand one measure
2. Do two measures move together?
3. Are groups really different?
4. Are two categories connected?
