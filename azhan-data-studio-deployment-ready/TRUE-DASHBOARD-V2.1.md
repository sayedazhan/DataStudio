# Azhan Data Studio — True Dashboard Shell v2.1

This release changes the desktop application shell, not the analytical calculations.

## What changed
- Persistent dark left navigation for Analyse, Compare, Forecast, Scenario and Statistics.
- Fixed compact application bar.
- Wider dashboard canvas and denser workspace spacing.
- Stronger KPI strip, chart cards and result panel hierarchy.
- Result charts receive more visual weight.
- Configuration areas read as dashboard filters/controls rather than long forms.
- Mobile/tablet retains the existing horizontal navigation pattern.

No backend algorithms or API contracts were changed.
