# Azhan Data Studio v3.3.1 - Data Quality refinement

## Changes
- Moved **Data Quality** to the second workspace tab, immediately after **Overview**.
- Added a prominent, live **Data Quality Score** card to the Overview dashboard.
- Made the score card clickable so it opens the full **Data Quality Centre**.
- Kept the existing supporting quality metrics (completeness, missing values, duplicate rows, fields with gaps) alongside the score.
- Added responsive styling for desktop, tablet and mobile layouts.

## Workflow
Analyse Single File -> Overview -> Data Quality -> Insights -> Explore -> Reports -> Fields
