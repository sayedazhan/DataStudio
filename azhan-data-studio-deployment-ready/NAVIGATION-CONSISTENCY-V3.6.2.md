# Navigation Consistency Patch — v3.6.2

## Fix
`Clean My Data` was visible in the left analytics navigation on the main Analyse page and the Clean page, but was missing from Monthly Intelligence, Compare Datasets, Forecast, Scenario, and Statistics.

## Change
Added the same `Clean My Data` navigation item immediately after `Analyse Single File` on all analytics tool pages.

## Result
The analytics workspace menu is now consistent across:
- Analyse Single File
- Clean My Data
- Monthly Intelligence
- Compare Datasets
- Forecast
- Scenario
- Statistics

No analytics calculations, API routes, SEO settings, domain settings, or payment links were changed.
