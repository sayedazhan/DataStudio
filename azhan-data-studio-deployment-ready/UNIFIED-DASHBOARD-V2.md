# Azhan Data Studio — Unified Dashboard Experience v2

This release standardises the result experience across all five main tools without changing the underlying analytical engines.

## Unified result pattern
- Dashboard-style result heading
- Consistent KPI cards
- A prominent **What this means** summary panel
- Consistent panel radius, spacing, hierarchy and typography
- Tool-specific evidence and charts remain distinct
- Existing reports/print output are unchanged

## Tools covered
1. Analyse — dashboard briefing + top finding meaning panel
2. Compare — comparison dashboard + plain-language change summary
3. Forecast — forecast dashboard + plain-language outlook summary
4. Scenario — scenario dashboard + decision summary
5. Statistics — retains the friendly evidence dashboard and joins the shared visual system

No backend calculation logic was changed in this release.
