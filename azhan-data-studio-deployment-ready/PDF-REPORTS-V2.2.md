# PDF Reports v2.2

Azhan Data Studio now provides a branded PDF-ready report from every major analysis option.

## Analyse
The existing detailed analytical report remains available and is now accessible directly from the Overview dashboard as well as the Reports tab.

## Compare
The comparison report includes record movement, numeric metric changes, schema changes, headline findings, and Explain Change driver summaries.

## Forecast
The forecast report includes current/forecast values, future forecast register with uncertainty ranges, highlights, and model diagnostics.

## Scenario
The scenario report includes Base/Upside/Downside outcomes, assumptions, key findings, and optional segment breakdowns.

## Statistics
The statistics report adapts to the selected question and leads with plain-English interpretation while preserving the relevant evidence and technical context.

## PDF generation
Reports use the browser's native print engine. Selecting **Download PDF Report** opens the print dialog; choose **Save as PDF**. This avoids adding a server-side PDF renderer and keeps Railway compute requirements low.
