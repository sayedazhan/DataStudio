# Azhan Data Studio v3.1 - KPI Alerts + Stronger Period Comparison

## Added
- Configurable KPI movement alert threshold.
- Direction-to-watch rule: any movement, decline only, or increase only.
- Optional minimum/maximum KPI target alerts.
- Browser persistence for alert preferences.
- Two-period direction-streak signals.
- Driver-concentration signals.
- Data-quality signals surfaced alongside KPI alerts.
- KPI-per-record comparison for previous/current periods.
- Historical average and current-vs-average comparison.
- Current-period rank across reporting history.
- Best/worst historical period cards.
- Historical volatility plus positive/negative movement counts.

## Preserved
- Existing Monthly Intelligence ingestion and IndexedDB library.
- Exact duplicate-file protection.
- Period detection and schema validation.
- Deterministic insights and movement drivers.
- Data Quality Centre.
- Analyse Single File, Compare, Forecast, Scenario, and Statistics modes.
- No LLM or external AI API is required for calculations or alert logic.
